# AI 短片創作七階段教學工作台

一個專為 AI 影片生成設計的 7 步驟全流程互動式引導工作台。完整收錄講師示範的五大提示詞架構，並提供即時提示詞變數生成、鏡頭分鏡管理、自動存檔與專案匯出功能。

🌐 **線上展示網址**：[https://yaoshuchin.github.io/1151109-ai-mv-studio/](https://yaoshuchin.github.io/1151109-ai-mv-studio/)

---

## 🌟 核心功能特色

1. **七階段步驟式引導 (7-Step Stepper Wizard)**
   - **階段 01：劇情發想與主題設定**（秒數、情緒調性、風格、角色發想）
   - **階段 02：角色設定與 Character Sheet**（正面、45度、側面、背面四視角設定）
   - **階段 03：分鏡腳本設計**（景別、畫面描述、台詞、時長拆解）
   - **階段 04：AI 圖像生成**（首幀圖生成、片頭主海報設計）
   - **階段 05：AI 動態影片生成**（圖生影片、運鏡指令組合器）
   - **階段 06：聲音與配樂製作**（純音樂 BGM、角色配音、音效）
   - **階段 07：影片剪輯與整合**（剪輯 5 步黃金 SOP、成片匯出）

2. **五大課堂提示詞生成器 (Live Prompt Generators)**
   - 包含即時動態替換欄位（時長、風格、角色、比例、標題等）。
   - 一鍵複製提示詞（附帶 Toast 動態通知與外連 ChatGPT / Claude / Gemini 捷徑）。
   - 完整提示詞庫總覽模式（Prompt Cheat Sheet Library）。

3. **互動式分鏡工作台 (Storyboard Studio)**
   - 線上即時編輯 01～06 鏡頭（景別、提示詞、字幕台詞、秒數）。
   - 自動累計片長總秒數與鏡頭完成率統計。
   - 支援自由新增、刪除、重設示範鏡頭。

4. **數據自動保存與匯出 (Data Persistence & Export)**
   - 自動保存（LocalStorage）使用者填寫之所有提示詞、分鏡與勾選清單。
   - 一鍵匯出全專案 Markdown 筆記（包含分鏡表與全套提示詞），支援複製與下載 `.md` 檔案。
   - 內建「載入示範案例」按鈕，快速載入新海誠風格《草地上的約定》全套範例。

## 🎓 應用的課程綱要與實施指引

本工作台特別針對中學科技領域與跨學科素養設計，支援以下四大課程主軸的專題實作：

### 1. 國中生活科技：AI 影音創作與數位內容設計
* **核心重點**：將工程設計流程（發想、設計、模型、評估）結合 AI 數位傳播技術。
* **實作應用**：
  - 運用 Character Sheet 四視角思維繪製發明構想多重視角。
  - 結合動態影片與旁白解說機構運動原理（如齒輪、連桿、自走車）。
  - 製作生活科技工坊安全操作與自造工具宣導短片。

### 2. 國中資訊科技：生成式 AI、提示詞工程與多媒體整合
* **核心重點**：深入探討生成式 AI 運作機制、結構化提示詞工程（Prompt Engineering）與資訊素養。
* **實作應用**：
  - 提示詞工程拆解：主詞定位、風格參數、光影與視角變數調校。
  - 跨模型多模態整合：文字生圖（Text-to-Image）、圖生動態影片（Image-to-Video）、文字生音樂（Text-to-Audio）。
  - 科技倫理省思：探討 Deepfake 數位深偽辨識、智慧財產權與合理使用原則。

### 3. 跨領域課程：SDGs、環境教育、生命教育及在地故事創作
* **核心重點**：結合社會、生物與藝文領域，讓 AI 短片成為具備人文溫度的社會倡議載體。
* **實作應用**：
  - **SDGs 永續目標**：SDG 14 海洋生態（減塑危機）、SDG 13 氣候行動倡議微電影。
  - **生命教育**：透過「陪伴動物老去」探討生命責任、同理心與生死議題。
  - **在地故事創作**：走讀家鄉百年老街與古蹟古厝，將耆老口述歷史轉譯為短片。

### 4. 彈性學習課程：短影音製作、數位敘事及創意專題
* **核心重點**：校訂彈性學習、影音創客社團與自主學習專題，掌握當代數位視聽語言。
* **實作應用**：
  - 30 秒至 60 秒數位敘事三幕劇結構（Hook、衝突、高潮）。
  - 導演分鏡思維：鏡頭景別、推拉搖移運鏡與音樂節奏對位（Beat Sync）。
  - 小組協同合作完成短片，舉辦班級微影展成果發表與互評。

## 🚀 如何開啟使用？

您可以直接以任何現代瀏覽器開啟：

### 方法一：直接點擊開啟
至資料夾 `c:\antigravity\1151109AI MV製作網頁\`，滑鼠雙擊 [`index.html`](file:///c:/antigravity/1151109AI%20MV製作網頁/index.html) 即可在瀏覽器中使用！

### 方法二：透過本機 HTTP 伺服器
在終端機中執行：
```bash
python -m http.server 3000
```
或
```bash
npx serve .
```
接著開啟瀏覽器訪問 `http://localhost:3000`。
