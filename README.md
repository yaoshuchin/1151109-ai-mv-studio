# AI 短片創作七階段互動教學工作台

一個專為 AI 影片生成設計的 7 步驟全流程互動式引導工作台。完整收錄講師示範的五大提示詞架構，並提供即時提示詞變數生成、鏡頭分鏡管理、自動存檔與專案匯出功能。

---

## 🌟 核心功能特色

1. **七階段步驟式引導 (7-Step Stepper Wizard)**
   - **階段 01：劇情發想與主題設定**（秒數、情緒調性、風格、角色發想）
   - **階段 02：角色設定與 Character Sheet**（正面、45度、側面、背面四視角設定）
   - **階段 03：分鏡腳本設計**（景別、畫面描述、台詞、時長拆解）
   - **階段 04：AI 圖像生成**（首幀圖生成、片頭主海報設計）
   - **階段 05：AI 動態影片生成**（圖生影片、運鏡指令組合器）
   - **階段 06：聲音與配樂製作**（純音樂 BGM、角色配音、音效）
   - **階段 07：影片剪輯與整合**（剪輯 5 步黃金 SOP、成片匯出）

2. **五大課堂提示詞生成器 (Live Prompt Generators)**
   - 包含即時動態替換欄位（時長、風格、角色、比例、標題等）。
   - 一鍵複製提示詞（附帶 Toast 動態通知與外連 ChatGPT / Claude / Gemini 捷徑）。
   - 完整提示詞庫總覽模式（Prompt Cheat Sheet Library）。

3. **互動式分鏡工作台 (Storyboard Studio)**
   - 線上即時編輯 01～06 鏡頭（景別、提示詞、字幕台詞、秒數）。
   - 自動累計片長總秒數與鏡頭完成率統計。
   - 支援自由新增、刪除、重設示範鏡頭。

4. **數據自動保存與匯出 (Data Persistence & Export)**
   - 自動保存（LocalStorage）使用者填寫之所有提示詞、分鏡與勾選清單。
   - 一鍵匯出全專案 Markdown 筆記（包含分鏡表與全套提示詞），支援複製與下載 `.md` 檔案。
   - 內建「載入示範案例」按鈕，快速載入新海誠風格《草地上的約定》全套範例。

## 🚀 如何開啟使用？

您可以直接以任何現代瀏覽器開啟：

### 方法一：直接點擊開啟
至資料夾 `c:\antigravity\1151109AI MV製作網頁\`，滑鼠雙擊 [`index.html`](file:///c:/antigravity/1151109AI%20MV製作網頁/index.html) 即可在瀏覽器中使用！

### 方法二：透過本機 HTTP 伺服器
在終端機中執行：
```bash
python -m http.server 3000
```
或
```bash
npx serve .
```
接著開啟瀏覽器訪問 `http://localhost:3000`。
